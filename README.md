# MnemoMarks (provisional name)

Trademark registers on your computer, with your own key for each office.

Lot 0 connects the **USPTO**: you create a USPTO.gov account and request an API key on
their Open Data Portal, paste the key here, and the app checks it with the USPTO. The
key is sealed by the host and never shown back to this cartridge.

Next: download the full register once, then only the daily changes, so a list of names
can be checked in one go by you or by an agent.

A search is not legal advice. Data: USPTO Open Data Portal (US government public data).

Design and status: `docs/architecture/135_memory-packs-catalogue.md` §7.
